Como consumir

O cliente calcula a própria data local e busca o arquivo daquele dia. Não há parâmetro de fuso horário porque não há servidor: é exatamente o que esta página faz.

const hoje = new Date().toLocaleDateString('sv'); // "2026-09-04"
const r = await fetch(`./v1/day/${hoje}.json`);
const dia = await r.json();
console.log(dia.reference); // "Salmos 28"
